# Clickkaar

Premium frontend-only Angular 19 application for a photography equipment rental platform.

## Stack

- Angular 19 standalone components
- Angular Routing
- Reactive Forms
- Angular Signals
- SCSS
- Bootstrap 5
- Angular Material datepicker, dialogs, and snackbars
- Mock JSON-style data through Observable services

## Run Locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Build

```bash
npm run build
```

## Notes

This app has no backend integration. Product, booking, wishlist, and blog data are mocked in frontend services.
